# Windows 使用者與工程詞庫

本頁描述開發中的離線管理功能；實際發布狀態以 Release 與驗收報告為準。

## 新增與修改

在設定的「使用者與工程詞庫」開啟管理頁。新增詞條時選擇中文詞彙、英文術語、技術別名或 Unicode 映射，再填文字與讀音／輸入碼。

例如希望輸入 `h2o` 時選出 `H₂O`，可新增 Unicode 映射，輸入碼填 `h2o`、文字填 `H₂O`。需要中文候選「水」時，在新增中文名稱填「水」，確認讀音填 `ㄕㄨㄟˇ`。中文名稱是獨立中文詞條；選取中文候選時輸出中文名稱，不自動改成符號。

按「產生異動預覽」，核對完整內容及關聯，再核准。取消不會變更管理詞庫。編輯既有條目會保留其中文關聯；新增中文名稱只追加關聯。若要改中文名稱或讀音，請編輯該中文詞條。

## 在 Mac 與 Windows 交換

1. 選取要匯出的詞條；未選取時匯出全部。SQLite 會一起包含相關中文名稱與工程詞，避免留下失去對象的關聯。
2. 匯出至新的檔名，再自行把檔案傳到另一台電腦。程式不會自動上傳或同步。
3. 在另一端匯入，選取條目並預覽。一般匯入合併內容，未列入的原有條目會保留；衝突預設保留本機內容。
4. 確認後核准，才能加入本機候選。外部檔案即使標記 approved，也不能代替此步驟。

選定條目的關聯可能使實際匯出／匯入筆數增加，請查看預覽。含關聯的詞庫不能匯出為舊版 JSON，以免遺失中文關係；請使用 SQLite。

## 原有詞庫與回復

原有自訂工程詞彙仍由原設定頁管理。新介面的匯入建立管理副本，不會移動或接管來源。下方保留舊版工程詞選取匯出入口；未確認中文讀音的名稱不會被自動猜測。私人原生詞庫與自動學習資料不會被讀取或移轉。

刪除管理副本不等於刪除原生候選，其他字典仍可能提供相同文字。「回復上一版」回到上一個成功核准的版本；「全量覆蓋回復」則用所選檔案完整取代目前管理內容，請仔細檢查預覽。

若主要 SQLite 無法讀取，程式只會採用通過完整性驗證的備份。兩份都損毀時不會猜測或覆寫檔案；執行中的輸入法保留最後一次有效索引，新啟動的輸入法則保留原生輸入。此功能不是任意損毀檔案的自動修復工具。
