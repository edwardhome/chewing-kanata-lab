# 延後方案：同步資料夾交換

狀態：已由使用者改為優先離線手動匯入／匯出。以下是保留的歷史規劃，不是近期實作要求；不註冊排程、不傳輸、不以過往接受衝突遺失視為手動匯入覆蓋授權。

## 最新選定方向：同步資料夾完整快照，遠端變動優先

各端維護本機工作 SQLite；使用者選定 Google Drive 等同步資料夾，交換檔名固定為 `lexicon.sqlite`。只讀此精確檔名，忽略衝突另名檔，不直接開啟同步路徑作活動資料庫。使用者選定：遠端已變動時直接採用雲端完整版本，放棄尚未上傳的本機修改，不逐筆合併、不重放 pending edits，也不要求每次人工選擇。此規則取代先前 dirty 優先，以及更早的 blob/head、CAS、雲端 API 與強制衝突確認提案。

定義 `base_sha` 為上次成功接受或交付發布的完整快照 SHA；`remote_sha` 為目前同步資料夾固定檔案的完整有效副本 SHA；`local_sha` 為一致本機候選快照 SHA。SHA 僅辨識內容，不提供來源授權或跨機時間先後。base 必須綁定選定同步位置，換位置重新進行首次同步。

| 狀態 | 規劃動作 |
| --- | --- |
| 遠端讀取失敗、半檔、損毀或版本不支援 | 保留本機與上次核准索引，不發布；不可當成檔案不存在或已變動 |
| 首次設定，已有有效遠端 | 驗證後採用遠端；不拿本機檔案直接覆蓋 |
| 遠端確定不存在 | 只有明確初始化才建立固定檔案；不因暫時同步延遲自動補建 |
| local_sha == remote_sha | 不傳輸，更新 base；僅在捕捉後本機未再編輯時清 dirty |
| remote_sha != base_sha | 遠端優先，放棄待發布本機修改；安全採用後更新 base，下載不設 dirty、不回傳 |
| remote_sha == base_sha，且本機有修改 | 發布經驗證的完整本機快照；不以修改後 local_sha 代替 base 判斷衝突 |
| 遠端與 base 相同，本機無修改 | 無動作，不於週期檢查重發 |

自動同步每週最多一次：自上次自動嘗試滿七天，於下一個可執行時機執行一次；休眠或關機漏掉多週只補一次。失敗保留狀態並等下一週，不連續重試。新增詞、整點、資料夾變更與一般啟動均不額外觸發；啟動只可執行已到期的單次補跑。保留使用者主動的一次「手動同步」，不受每週限制，仍遵守上述雲端優先規則，失敗不產生重試迴圈。相同 SHA 不重複載入；每次一般發布前比較 remote 與 base，不以 local 與 remote 不同推斷遠端變動。

另設清楚區分的「強制上傳」按鈕，僅使用者明確手動觸發，不受每週限制；跳過 remote != base 時先下載的分支，以本機完整且核准的快照覆蓋指定位置的 lexicon.sqlite。此動作不合併詞條，可能覆蓋另一端內容；一般「手動同步」不得暗中使用此模式。強制上傳仍驗證完整性、核准內容、固定路徑與安全寫入，不能把讀取失敗當成一般同步的強制發布理由。成功交付後更新捕捉快照的 base；僅捕捉 generation 未再變更時清 dirty，後續編輯仍保留 dirty。寫入失敗不更新 base、不丟本機修改。排程與 AI 絕不自動觸發強制上傳。

以 SQLite 備份 API 或一致交易產生獨立封閉 SQLite 快照，不依賴活動中 -wal/-shm；不得把 JSON 當成 SQLite 或只複製可能尚未 checkpoint 的主檔。驗證 schema、完整性、容量、讀音與詞條語意，再透過同資料夾暫存檔與本機替換交付固定檔名。成功只能顯示「已交付同步軟體」，不能宣稱另一台已收到。發布失敗保留 dirty；發布 generation N 時若本機又有 N+1 修改，成功僅更新此次快照 base，不清除新修改 dirty。遠端採用與本機編輯須由管理層序列化，避免非同步回呼覆寫採用後的新交易。

下載先取本機暫存副本、驗證完整 SQLite，再於安全邊界採用。活動組字不可因 timeout 強制切換或吞字；保留當前快照至安全閒置，採用前再次核對本機 generation 與待採用來源。下載／採用本身不標 dirty；只有採用後的新本機編輯才標 dirty。可規劃有限本機恢復備份，但不承諾保存全部修改，也不以備份變相逐筆合併。

同步資料夾沒有服務端 CAS：檢查與替換之間可能被其他裝置寫入，使用者接受整份遺失，不宣稱嚴格全序、最後編輯者必勝或端到端原子。檔案 mtime、各機序號、hash 排序都不能選勝負；目前收到的有效固定檔案就是可比較內容。不保證供應商產生衝突副本或保留全部歷史。未完成下載保留舊版，等下週或使用者主動手動同步，不忙迴圈重試。

AI 僅於遠期評估發布時機，不授權自動核准模型新詞。本輪只更新設計與合成測試矩陣，不實作同步服務。
