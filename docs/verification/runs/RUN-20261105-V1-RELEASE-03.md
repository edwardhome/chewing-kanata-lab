# v1.0.0 升級與解除安裝驗證

更新時間：2026-11-05T17:50:35+08:00

使用者要求調查 Windows 輸入法清單無法移除預覽版，並將目前已驗收版本合併定為 v1.0.0。此授權包含本輪版本整合、安裝與發布；不代表尚未完成的 AI 功能已實作。

## 發現與處理

檢查時，獨立預覽版仍有 HKLM TSF 語言設定檔與 HKCU COM 註冊，卻沒有 Windows「已安裝的應用程式」解除安裝項目；先前舊版使用上游 GUID 的 COM／TIP 註冊已不存在。沒有取得 Windows 設定 UI 的錯誤訊息，因此不將該 UI 的特定失敗機制宣稱為已重現。

本輪為獨立身分補上完整解除安裝入口，使用 TSF `ITfInputProcessorProfiles::Unregister` 移除整個本產品服務，取代逐一語言 profile 移除。Microsoft 說明此 API 用於 [從 TSF 移除指定 CLSID 的服務](https://learn.microsoft.com/en-us/windows/win32/api/msctf/nf-msctf-itfinputprocessorprofiles-unregister)。僅刪除本產品 COM、ProgID、current.json 與 Windows 解除安裝項目；保留版本檔案、使用者詞庫與偏好。

安裝／解除安裝需要 TSF 系統註冊權限時，透過標準 RunAs 提升權限，並核對相同使用者 SID；其他帳號會在變更前被拒絕。這一輪使用已具權限的 SSH runner，沒有宣稱實測互動 UAC 對話框。

沿用相同獨立 GUID、ChewingDev 路徑與 F／英文組字實作，只把顯示名稱改為「AI新酷音」；Cargo 產品版本 1.0.0、DLL 檔案及產品版本 1.0.0.0，另附 version.json。原始上游授權與歷史保留。

依序執行，全部 PASS：
