## 建置環境問題

不同 Cargo.lock 的工作區共用 CARGO_TARGET_DIR 時，lib/cdylib/staticlib 產物造成 serde_core 1.0.228／1.0.229 型別不一致。核心改用獨立 target 後通過；後續核心、原生與設定程式必須各用獨立建置目錄。這不是透過變更契約或略過測試解決。
