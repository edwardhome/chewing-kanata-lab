AI新酷音 1.1.1 新增 Windows／Mac 共用個人詞庫交換，沿用 `ai-bopomofo.lexicon` 格式 1.0.0。

## 新增功能

- 設定頁提供共用詞庫匯入、差異預覽與本機明確確認；取消預覽不寫入詞庫。
- 獨立儲存、完整性校驗、原子切換及回復前版；組字中不切換候選快照。
- 共用中文詞加入原生選字清單，保留原生順序並要求明確選取。
- 選取自訂工程詞後匯出交換檔；來源過期與既有目的檔案覆寫均會阻擋。

## 下載與驗證

下載 `AI-Chewing-Windows-x64-1.1.1.zip`，依 `SHA256SUMS.txt` 核對。`SOURCE-MANIFEST.json` 記錄套件及三個來源提交，`VERIFICATION.md` 記錄驗證與限制。設定頁「軟體更新」可手動檢查／下載；不自動安裝。

正式版本重新編譯，並非開發版 ZIP 改名。270 項測試通過、1 項略過；前端、原生及設定程式 Release 建置通過。完整 patch 重播與套件驗證結果見附件。

## 已知限制

- `zh_aliases` 不在格式 1.0.0 內，預設拒絕有損匯出；使用者明確允許省略時會列出確切清單，保留原始資料。
- 未實作私人中文詞庫自動匯出；不直接同步各平台內部資料庫或學習分數。
- 格式編解碼無損不代表部署後元資料相同；Mac 核准流程會調整 review／usage，Windows 以獨立本機 receipt 授權。
- GUI、實體按鍵、實際安裝／解除安裝端到端驗收仍為 **NOT_RUN**；測試通過不等於所有應用程式均已實測。
- 20,000 筆 debug 合成案例曾測得索引建立約 39 ms、查找加候選快照約 19 ms；此為單次開發量測，不是正式效能保證，大量同音候選仍需實機評估。
- Ollama 尚未接入 TSF 預測，未啟用背景輸入蒐集。
- 本套件未以私人憑證簽署。本次發布沒有遠端安裝或重啟使用者輸入法。

發布後另以設定程式的實際 GitHub 查詢測試驗證連線：1 項通過；公開 ZIP 下載摘要一致。
