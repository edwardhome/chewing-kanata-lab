# 應用程式輸入模式（Windows 1.3.0-dev.1）

此功能預設關閉。它只決定 AI新酷音已啟用時，進入應用程式後使用英文或注音；不會替使用者切換系統輸入法。

## 設定方式

1. 開啟 AI新酷音設定，進入「應用程式」。
2. 開啟功能，按「從已開啟的 App 選擇」，選擇目標程式再加入。也可以選擇本機 `.exe` 檔案；請選實際執行程式，不要選啟動器或捷徑。
3. 每個 App 選擇英文或注音，按「套用」或「確定」。
4. 切至另一個 App，再返回目標 App，套用預設模式。

程式以完整執行檔路徑識別。同名不同路徑可以分別設定；程式搬移或版本更新改變路徑後，請重新加入。已開啟 App 清單僅列出有可見視窗且能取得身分的程式，顯示執行檔名稱，不讀取視窗標題。

同一 App 內手動切換後，換欄位、視窗或分頁仍保留手動選擇。離開並返回才重新套用預設。修改規則、刪除或停用也在下一次進入 App 生效，不打斷目前輸入。啟用 Caps Lock 控制中英模式時，以 Caps Lock 為優先，App 規則不套用。

組字、候選、待處理編輯及 F／Shift 手勢尚未結束時延後切換，不自動送出或刪除文字。無法確認前景程式或可編輯輸入連線時跳過規則，維持輸入法原有行為。部分使用宿主程序的 Windows App 可能無法辨識，須實機確認。

## 資料範圍

規則保存在本機設定。不同輸入法程序透過本機登錄值分享「目前一次 App 造訪」及模式，不建立 App 使用歷史；不記錄按鍵、文件、視窗標題或輸入文字，也不呼叫 AI。停用後不套用規則。設定頁只在使用者要求列出 App 時查詢可見程式。

## 測試版驗收

- 先確認關閉功能時，記事本、Word、開始列搜尋與原有 F／Shift 輸入正常。
- 將記事本設英文、Word 設注音，切換 App，確認預設模式。
- 在記事本手動改注音，再換記事本視窗／欄位，確認不被搶回英文；切到 Word 再回來才應恢復英文。
- 選其他系統輸入法後切換 App，確認 AI新酷音不會搶回。
- 快速切換、組字中切換、修改／關閉規則，確認沒有漏字、重複送字或強制確認候選。

這是測試包，尚未宣稱上述 Windows 實鍵行為通過。不包含舊 F parity 分支的新行為；以已驗收 1.1.5 為基準。
