# ADR-0005: 本機 AI 候選字重排序 (Reranker) 契約決策

- **狀態**：已批准 (Approved)
- **日期**：2026-10-22

## 背景
導入 LLM 時最常見的災難是模型隨意生成字詞、打字卡頓、吃光 VRAM。

## 決策
1. AI 角色限定為**重排序器 (Reranker)**，絕不輸出原候選清單以外的文字。
2. 透過 `ai_reranker_validate_response` 進行硬性白名單過濾，發現非法 ID 或重複直接整批作廢。
3. 異步非同步呼叫，設定 150ms 超時，逾時直接丟棄結果，輸入法主線程絕不等待 HTTP。
4. 預設關閉，離線或無 Ollama 時 100% 正常運作。
