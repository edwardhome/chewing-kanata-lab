## 傳輸與協定

- 固定 `127.0.0.1:11434`，禁止代理與重導向；連線 250 ms、整個請求與內文共用 2 秒期限；標頭 8 KiB、內文 16 KiB。
- 只回傳受限位元組及固定錯誤分類；審查移除了可能含回覆文字的底層錯誤字串。
- 取消在送出前及遞交結果前檢查；進行中的阻塞 I/O 最晚由期限收束，不宣稱立即中斷。
- `/api/tags` 僅選擇已安裝 GGUF 本機模型，排除遠端模型欄位與 cloud 名稱。此 metadata 檢查不是本機服務的安全沙箱，部署仍需確認 Ollama 本身未啟用雲端回退。
- `/api/chat` 使用結構化 JSON、`stream:false`，拒絕截斷、模型不符、工具呼叫、前綴改寫與不合法續寫；原文保留至使用者明確選取。
- 模型探索應在設定／準備階段完成，不占用從組字預測開始計算的 2 秒生命週期期限。

## 設定與交付界線

使用者所說「GitHub 更新」指設定內檢查與下載新版，不只是同步程式碼。查詢只在按鈕觸發時執行，固定本專案 GitHub API、8 秒期限、512 KiB 上限，拒絕預覽／草稿及外部下載網址；安裝包交由瀏覽器下載，使用者自行安裝。

[工程詞彙需求與模型協作邊界](USER_ENGINEERING_TERMS_102.md) 已分開記錄。第一版個人詞庫於輸入法服務建立時讀取，儲存後需重開使用輸入法的應用程式；尚無即時重載。

本批不宣稱 Ollama 已接入 TSF 候選，也不背景蒐集打字歷史。即時工程辨識、模型設定、TSF 工作者通知與候選呈現仍為後續項目。測試包以 `1.0.2-preview.1` 區分；正式 1.0.2 尚未發布。
