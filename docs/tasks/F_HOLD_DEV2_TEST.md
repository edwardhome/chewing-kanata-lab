# Windows 1.3.0-dev.2 測試說明

本版新增 F 按下即顯示原字的可撤回預覽；超過設定時間才撤回本次 F 預覽並進入數字／符號層。預設 150 ms，沿用使用者已有設定。安裝由使用者操作，請先儲存工作，解壓縮後執行 install_ime.bat，再重新開啟測試應用。

## 驗收順序

1. 標準注音按下 F，尚未放開、尚未達門檻時應顯示 ㄑ。短按保留一次 ㄑ；快速 fu、fm、fr 按原注音流程處理，不提前出現映射符號。其他鍵盤配置使用引擎實際讀音。
2. 直接英文按下 F 先顯示 f；短按只有一次 f，快速 fr 為 fr。長按超過門檻時預覽改為未提交的 · 佔位，再按 R／U／M 為 +／8／2；F 放開才確認符號，空分層放開不留下 ·。
3. 中文已組出的字、游標前後文字與 ASCII 組字中重複上述操作。F 預覽應插在游標位置，不能遮掉或刪除原有文字；長按期間退格只刪分層內符號。
4. Shift+F 保留既有英文大小寫功能，不啟動 F 分層。未完成的注音音節、中文候選選單仍由原生引擎處理，不攔截 F。
5. 長按期間切換 App、欄位、中英模式，再返回輸入；不能在新位置出現舊手勢的符號或被晚到計時器切入分層。測試快速放開與 F／映射鍵不同放開順序。
6. 記事本、Word、Windows Terminal 各測一輪；App 規則維持 dev.1。Terminal 若更新過，請從已開啟 App 重新加入規則，以免完整執行檔路徑已失效。

自動測試與編譯通過不等於上述實鍵驗收完成。這次未加入推測性的 Terminal 同 PID 放寬判斷；不修改 Kanata，不安裝或重啟輸入法，不改私人詞庫。
