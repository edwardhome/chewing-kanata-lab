# 首字母長按轉小寫：Windows 對齊需求

狀態：待實作與驗收；2026-11-10 接收 Mac 負責者轉交的使用者最新需求。此紀錄不代表 Windows 已完成或通過測試。

## 行為契約

- 首字母長按使用獨立計時，不以作業系統 repeat 延遲作為唯一門檻。
- 第一層選單提供 100～1000 ms 設定，預設 250 ms；與 F 分層時間分開保存、分開生效。
- 短按 Shift+S 保留大寫 S；持續按住字母 S 到門檻後改為小寫 s。
- 先放開 Shift、仍按住 S 時，計時仍有效。
- repeat 事件只消耗，不提前觸發轉換，不連續輸出 s。
- 放開字母、換字、編輯、快捷鍵、模式或焦點改變，以及安全輸入情境，都取消待執行轉換。
- 保留 F 層優先與既有中文組字送出行為；延遲回呼不得修改已失效或已送出的組字。

## 驗收與工作邊界

- 覆蓋門檻前後、設定上下限、先放 Shift、repeat、取消條件與 F 優先的自動化測試。
- 實體按鍵及 Windows Word 回歸測試需另外記錄，不以 Mac 測試結果代替。
- Mac 參考分支為 `fix/initial-letter-hold-delay`，最新交付目標 1.0.3（先前 dev.2／1.0.1 名稱已被新決定取代；Windows 維持自己的版本序列）；只讀參考。
- SQLite 格式不變，不覆蓋目前共用詞庫未提交工作。
- 不安裝、不重啟輸入法。使用者其後授權本輪驗收通過後推送 GitHub 並發布 Windows 1.1.2；需實機驗證時先交付帶後綴的測試版，不宣稱已通過。
