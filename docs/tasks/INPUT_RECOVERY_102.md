# 1.0.2：恢復中文輸入

更新時間：2026-11-06T15:35:01+08:00

## 使用者症狀與分工

使用者回報「切到中文仍只能輸入英文」，要求提供 Restart，並指定 AGY 參與實作。這是 Windows AI新酷音工作，不變更 Mac 輸入法。

- AGY：原生 TSF 狀態恢復、原生選單、按鍵與模式回歸測試；作者名稱 AGY。
- Codex：完整設定頁入口、原生審查、來源同步、patch series、成品驗收。
- 第二個 AGY 工作階段：唯讀檢查恢復通道與邊界，僅撰寫專屬審查報告。
- Zbook：使用者自行安裝、移除與實體按鍵驗收；開發端不操作其電腦。

## 行為契約

Restart 是重新初始化本輸入法的暫態狀態並要求恢復中文，不是終止應用程式或重新載入 DLL。不得終止 Explorer、ctfmon、TextInputHost 或使用者應用，不重新註冊輸入法、不重設偏好或個人詞庫。

設定頁以明確按鈕送出 `HKCU\Software\ChewingDev\InputRecoveryRequest` QWORD，內容為 Unix epoch 毫秒。原生各實例追蹤已處理 token，僅在 30 秒期限內、安全輸入焦點且未組字、未按住修飾鍵或 F 時處理。過期、未來時間、未知或不可編輯脈絡均不可冒充恢復成功。這是短期控制要求，不是持久 Config 欄位。

設定頁顯示「已送出恢復要求」，提示使用者返回原欄位、放開按鍵，先完成或自行取消組字；未收到原生確認前不顯示已成功。CapsLock 設定若要求英文，不可偷偷改偏好。

修正焦點切換漏掉 Shift key-up 時的殘留狀態，並在重建 editor 後保持語言模式一致。TSF compartment 更新必須在可重入安全區進行，不能在可變 RefCell 借用中呼叫。

## 驗收案例

以下 GUI／實鍵項目須由使用者安裝後確認，程式建置不能代替：

1. 中文空組字下輸入注音；Enter 與退格仍正常放行。
2. 按住 Shift 切到其他視窗，放開 Shift 後回來；中文不應永久變成英文。
3. 正常 Shift＋字母、短 Shift＋F、F 長按符號與雙 Shift 切換仍符合原有行為。
4. 設定頁送出 Restart，30 秒內回到中文欄位；確認可輸入注音。
5. 有未送出組字或候選時要求恢復；文字不可被清掉或意外送出。先完成／取消後再試。
6. 保持 Shift／Ctrl／Alt／Win／F 按下時要求恢復；不在手勢中間重設。
7. 讓要求逾期後才返回；不應於很久以後突然切中文。
8. 密碼、不可編輯與未知脈絡不啟動恢復攔截；CapsLock 設定保持原樣。
9. 更新後須重新開啟使用輸入法的應用以載入新 DLL；Restart 不能把舊 DLL 熱更新。

Ollama 候選接線與背景內容蒐集不屬於本項；不得為恢復功能新增輸入紀錄。
