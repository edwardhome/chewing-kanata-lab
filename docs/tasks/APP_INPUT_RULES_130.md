# Windows 1.3.0：應用程式輸入模式規則

本輪由使用者授權從已驗收的 1.1.5 main 繼續開發，僅新增 App 切換功能。版本交付為 1.3.0-dev.1，待使用者實鍵驗收；不安裝、重啟、合併 main 或發布正式 Release。

## 分工與來源

- Codex：Preferences 新分頁、使用者操作、封裝、獨立驗收。
- AGY：policy-core 狀態與測試、Windows 前景身分／TSF 介接、設定保存。
- 基線：outer c0e23d1；native 4330752；preferences 08cf8ce。
- 分支：feature/app-input-rules-1.3.0。
- 舊 F parity 修改另存於原分支，native 2764c70；這輪不納入。F／Shift／詞庫行為以 1.1.5 為準。
- Mac 僅唯讀參考；此規格不代表兩平台已實機驗收。

## 使用契約

1. 預設關閉，清單空白。使用者選擇已安裝的本機 exe，新增、刪除或選擇英文／注音，不需要編輯私人設定檔。
2. 使用完整程式路徑識別，不依視窗標題或只依檔名。同名不同路徑是不同 App；搬移後重新加入。
3. 每次切入 App 使用當次設定快照；同 App 手動切換保留，不因欄位、視窗、分頁重建搶回。離開 App 再返回才重新套用。
4. 設定、刪除、總開關變更在下一次 App 切入生效。未設規則維持舊行為。
5. 只改 AI新酷音內部模式，不強制選取系統輸入法。
6. 組字、讀音、選字、待處理編輯、F／Shift 手勢期間延後；不可提交、刪除文字或接受預測。手動切換取消本次待套用預設。
7. 過期前景事件或輸入連線不能套用至新連線。未知身分或安全欄位不套用。
8. 不辨識 Vim、網頁、檔案、SSH、tmux；不讀文件或全域打字，不呼叫 AI。

## 設定格式

ChewingTsfConfig：app_input_rules_enabled=false；app_input_rules_json={"version":1,"rules":[]}。
每筆包含 app_id、display_name、mode（english 或 bopomofo）。大小上限 1 MiB、256 筆；版本未知或格式錯誤回退空規則。重複加入不得覆寫原本模式。

## 使用者驗收矩陣

- 關閉功能：記事本、Word、開始列搜尋及原有中英切換保持 1.1.5 行為。
- 記事本規則設英文，另一個 App 設注音。切出去再返回，預設正確。
- 記事本內手動切注音，再換視窗／欄位，不能被搶回英文；跨 App 返回才重套英文。
- 規則啟用時選其他系統輸入法，切換 App 不得搶回 AI新酷音。
- 快速往返 App、關閉重開視窗，不能由背景事件切錯前景模式。
- 組字／候選／F／Shift 過程沒有漏字、重複送字或自動接受候選。
- 修改或刪除規則／關閉功能時，當前輸入不被打斷，下一次切入才生效。
- 取消檔案選取無變更；重複加入原模式不變；同名不同路徑可分別設定。

自動測試與編譯只能證明受測邏輯及產物，不能替代上述 Windows 實鍵驗收。
