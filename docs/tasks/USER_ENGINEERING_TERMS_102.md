# 1.0.2 自訂工程詞彙

更新時間：2026-11-06T10:52:42+08:00

## 使用者需求

使用者在 Zbook 操作時發現 `SiO₂`、`H₂O₂` 可選，卻沒有 `H₂O`，希望能自行新增工程詞彙。Zbook 是使用者端，由使用者安裝、移除及操作驗收；開發代理不登入該機器。

## 已查證現況

- `policy-core/resources/engineering-terms.json` 內建 103 個詞條，有 `sio2`、`h2o2` 別名，沒有 `h2o`。
- `EngineeringLexicon::bundled()` 在編譯時嵌入該檔案。修改安裝目錄附近的 JSON 並不會改變候選。
- `TechnicalLexicon::load_from_file_or_default()` 讀取 `%APPDATA%\ChewingDev\technical-terms.txt`，支援每行一詞；這是文字前綴補全，並非輸入碼到輸出文字的映射。
- 因此新增一行 `H₂O`，不能讓 ASCII `H2O` 匹配它；新增 `H2O H₂O` 或 `H2O=H₂O` 也不是現有支援格式。
- TSF 建立服務時載入此詞庫；尚無儲存後即時重新載入的完整使用者流程。
- 1.0.1 的完整原生設定頁尚無自訂工程別名編輯分頁。歷史滑桿設定程式中的記事本按鈕，不代表目前原生設定頁已具備此功能。

## 待實作的使用者流程

右下角輸入法選單 → 設定 → 自訂工程詞彙 → 新增：

| 欄位 | 範例 |
| --- | --- |
| 輸入碼 | `H2O` |
| 候選文字 | `H₂O` |
| 註解 | 水 |

提供新增、編輯、刪除、文本匯入預覽及匯出；儲存失敗須明確提示。候選保留原文，使用者明確選取才送出排版形式。此功能不依賴 Ollama 或網路。

## 開發與驗收邊界

- 個人詞條與內建詞庫分開保存於 AI 新酷音自己的使用者資料目錄，升級時保留；不讀取或修改正式新酷音既有個人詞庫。
- 保留現有 `technical-terms.txt` 相容性；新增映射使用有版本的格式，勿默默改變既有格式語意。
- 避免靜默覆蓋重複輸入碼；允許同一輸入碼有多個候選，去除完全重複的候選，保留大小寫及上下標。
- 驗證長度、數量與控制字元；採完整驗證後原子寫入，失敗保留前一版，不將私人詞彙記錄到日誌。
- 第一版儲存後需重新開啟使用輸入法的應用程式，設定頁清楚顯示此限制。未來即時重新載入應不阻塞輸入；正在組字時延後更新，避免候選選取位置突然改變。
- 補上 `H2O → H₂O` 內建詞條，並以 `H2O2 → H₂O₂` 測試兩者不混淆。
- 自動測試包含新增、重複、刪除、損毀檔案、升級保留及候選排序。
- Zbook 實機驗收：新增後候選可見、原文仍可送出、重新開啟與升級後保留、刪除後不再出現。

狀態：開發分支已實作內建 H₂O、個人別名映射、設定表單、附註解與大模型提示詞的批次文本、匯入預覽與匯出。核心 110 項測試通過；設定程式編譯與使用者實機驗收另列紀錄。尚未發布，不能視為 Zbook 已安裝。

## 文本與模型分工

- 批次文本為 UTF-8 TSV，三欄以 Tab 分隔；# 開頭行為說明與可複製給外部模型的提示詞。範本包含 H2O、CH4、i2c 範例。
- 模型輸出先匯入表單預覽，使用者確認儲存；不直接讓模型覆寫個人詞庫。
- 匯出只包含已儲存的自訂詞彙及固定提示詞，不包含組字歷史、剪貼簿、文件或正式新酷音個人詞庫。
- 後續可研究以目前未送出的組字為輸入，由 Ollama 建議 CH4 等工程候選；前後文目前仍限於同一未送出的組字，不延伸讀取文件或已送出文字。
- 「累積待校正項目」屬遠期功能：須另外設計明確啟用、可檢視／刪除、容量與保存期限及使用者主動匯出流程。這一版不背景記錄日常輸入，不自動傳送外部模型。
